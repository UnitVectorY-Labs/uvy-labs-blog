# uvy-labs-blog

Blog for [UnitVectorY-Labs](https://github.com/UnitVectorY-Labs), published at [blog.unitvectorylabs.com](https://blog.unitvectorylabs.com).

Built with Jekyll using the [UnitVectorY-Labs Design](https://github.com/UnitVectorY-Labs/uvy-design) style language (`assets/css/uvy.css` and `assets/js/uvy.js`) plus a blog presentation layer (`assets/css/uvy-blog.css` and `assets/js/uvy-blog.js`). Posts in `_posts/` are automatically researched and generated by [release-storyteller](https://github.com/UnitVectorY-Labs/release-storyteller).
