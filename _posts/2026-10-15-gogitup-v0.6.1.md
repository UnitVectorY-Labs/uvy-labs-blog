On October 15, 2026, gogitup v0.6.1 was released for the Go tool automation CLI that keeps `go install` tools up to date. This is a focused stability release that makes the output of `list`, `check`, and `upgrade` predictable and consistent, with no breaking changes and no migration work required.

gogitup lets you register Go module paths in `~/.gogitup` and run a single command to see which tools have updates and upgrade them. v0.6.1 improves the user experience by ensuring the tools are always presented in the same order, regardless of how they appear in the config file.

## What's new

Deterministic alphabetical processing

The headline change in v0.6.1 is deterministic ordering of registered apps. `list`, `check`, and `upgrade` now process and display binaries alphabetically by name, ignoring case with a case-sensitive tie-breaker. The order you wrote in `~/.gogitup` is preserved on disk, but it no longer affects command output.

This means tables, JSON output, per-app diagnostics, version checks, and upgrade steps appear in the same predictable order on every run and on every machine.

Documentation updates

The docs were updated to reflect the new behavior. `docs/CONFIG.md` and `docs/USAGE.md` now note that command output and processing use alphabetical order by binary name, so users can rely on stable ordering for scripts and manual review.

## Why it matters

Predictable output reduces friction. When you run `gogitup check` or `gogitup upgrade`, you now get a consistent view of your toolset that is easy to scan and compare across runs. For users who script around gogitup output or just want a calm, repeatable workflow, alphabetical ordering removes the surprise of config-file order leaking into the terminal.

There is no functional change to which tools are updated. The same set of registered apps is checked and upgraded; only the presentation order changes. No flags, commands, or configuration schema were added or removed.

## Upgrade and installation

Upgrade is straightforward and requires no migration:

```bash
go install github.com/UnitVectorY-Labs/gogitup@latest
```

Prebuilt binaries for darwin, linux, and windows are available in the release assets. Existing `~/.gogitup` configuration continues to work unchanged. You will simply notice the new alphabetical ordering in `list`, `check`, and `upgrade` output.

If you rely on visual position rather than tool name, expect the list to reorder on first run after upgrading. The behavior is documented and stable going forward.
