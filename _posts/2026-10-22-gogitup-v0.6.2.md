## Why it matters

gogitup automates checking and updating of tools installed via `go install`. Because it is frequently downloaded as a prebuilt binary, the trustworthiness of the build toolchain matters for supply-chain security. Rebuilding with Go 1.27.3 ensures the binaries are produced with a toolchain that explicitly distrusts the compromised eMudhra intermediate CAs, reducing risk from certificate validation during future builds or network operations.

For users who install from source with `go install github.com/UnitVectorY-Labs/gogitup@latest`, the source code is unchanged from v0.6.1, so behavior remains identical. For users who prefer the provided binaries, v0.6.2 is a drop-in replacement that preserves all existing functionality while improving build provenance.
