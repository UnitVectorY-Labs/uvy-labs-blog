On October 6, 2026, clip4llm v1.2.3 was published. This is a maintenance update that keeps the project’s dependencies current and strengthens the repository’s security practices, while leaving the CLI experience unchanged from v1.2.2.

clip4llm remains a command-line tool for copying project files to your system clipboard so they can be pasted into LLMs such as ChatGPT. The tool filters by file type, size, and patterns, respects hidden files and configuration overrides, and formats output for easy prompting.

## What's new

v1.2.3 contains no functional changes to the clip4llm CLI. Application code, configuration handling, and file selection logic are identical to v1.2.2.

- The `isplaintextfile` dependency is bumped to 0.1.1, with no documented user-visible API changes.
- GitHub Actions dependencies for CodeQL and setup tools are updated to their latest supported versions.
